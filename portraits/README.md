# Class portraits

Put one image per class in this folder and the site shows it on the reveal screen instead of the job-type emoji. Classes without an image keep the emoji.

- Name each file exactly as listed below, with a `.png`, `.webp` or `.jpg` extension.
- Transparent PNGs of roughly 500 px tall look best; the image is shown as a black silhouette first, then in colour.
- MapleStory artwork belongs to Nexon, so check their fan-content terms before publishing it.
