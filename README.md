# Maple Roulette

A single-page gacha-style wish scene that picks a random MapleStory class.

- Press WISH (or Space) to call down a glowing maple leaf and reveal a class; click the scene to skip the animation.
- Filter by class group (Explorer, Cygnus Knights, ...) and job type.
- Optional "no repeats" mode and a pull history, saved in your browser.

It is one static file, `index.html`, with no build step. To edit the class list, change the `CLASSES` array near the top of the script.

## Publishing with GitHub Pages

In the repository on GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, pick the branch holding `index.html` and the `/ (root)` folder, then save. The site appears at `https://zykros.github.io/Maple_roulette/` after a minute or so.
